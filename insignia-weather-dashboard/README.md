## 🌤️ Insignia Weather Dashboard

A real-time weather dashboard with local forecasts, alerts, and a clean UI.

### Features
- Real-time weather data from OpenWeatherMap
- Local forecasts for your city
- Weather alerts (e.g., thunderstorms, heavy rain)
- Responsive design (mobile & desktop)
- Built with HTML, CSS, and JavaScript

### How to Use
1. Copy this project into a local folder.
2. Replace the API key in `config.js` with your OpenWeatherMap API key.
3. Open `index.html` in your browser.

### API Key
⚠️ Replace the placeholder API key in `config.js` with your own.

```js
const API_KEY = "your_openweather_api_key_here";
```
